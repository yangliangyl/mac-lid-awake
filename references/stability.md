# 稳定性升级与工具迁移

仅在配置反复漂移、用户要求彻底解决/自动守护，或考虑替代工具时读取。本流程不承诺绝对永不失败；目标是单一所有者、可验证、故障安全和可恢复。

## 进入条件

满足任一条件才升级：

- `SleepDisabled` 在修复后再次回到 0，且不是用户主动关闭。
- 双向供电回归失败。
- 任意 `pmset` 写入后合盖状态被清除。
- 用户需要长期无人值守的 Codex、Claude Code、Cursor、构建或本地服务。

先运行 `setup_audit.py`。若发现多个合盖工具，先明确唯一所有者；不要通过叠加应用解决漂移。

## 方案顺序

1. **保留 Amphetamine，增强核验**：适合偶发使用。向用户说明影响并确认后，使用带显式所有者与所需 `--allow-*` 参数的 `ensure`；每次供电或电源设置变化后先只读检查。重复漂移时不再宣称稳定。
2. **迁移到单一原生工具**：用户希望菜单栏方案且不愿维护守护脚本时，优先评估已签名、公证并使用受限特权助手的实现。当前候选优先看 [Amped](https://github.com/gustaferiksson/amped)；安装前重新核对最新发布、签名、权限范围和维护状态。迁移时先关闭 Amphetamine Closed-Display Mode 并验证 `SleepDisabled=0`，再启用新工具，避免双重所有权。
3. **任务感知保活**：用户只想在 Agent 工作时保活，可评估 [Adrafinil](https://github.com/kageroumado/adrafinil)。Hook 会修改 Agent 配置，安装前必须展示涉及的 Codex/Claude/Cursor 文件并获得用户确认。不要仅靠进程名判断任务仍在工作。
4. **离开电脑/手机远控**：需要热点、网络切换和有期限会话时，可评估 [rucksack](https://github.com/noahnawara/rucksack)。其租约、TTL、故障恢复和网络前置检查是合适模型；项目成熟度低时先审计代码与发布签名，不直接替换生产配置。
5. **商业成品**：希望温度、电量、任务识别一体化且接受闭源付费，可评估 [LidRun](https://github.com/aibrickai/lidrun)。不能把 GitHub 文档仓库误称为开源实现。

StayAwake、macowl 等未公证或用户量较少的项目可作代码参考，不作为新手默认安装。KeepingYouAwake 和普通 `caffeinate` 只解决闲置休眠，不能单独作为合盖方案。

## 自建守护的必要属性

只有用户明确要求安装自动守护时才能落地。实现必须具备：

- **唯一所有者**：启用前拒绝已有 `SleepDisabled=1` 且来源不明的状态；不与 Amphetamine、Amped 等同时控制。
- **租约而非永久开关**：默认有限期限，支持续租；到期恢复进入前的基线状态。
- **故障安全**：守护、客户端或 Agent Hook 消失后，TTL 到期自动恢复休眠。不能让一次崩溃永久留下 `disablesleep=1`。
- **事件优先**：监听供电变化、唤醒和登录，事件后立即核验；60 秒轮询仅作兜底，不用 30 秒高频轮询。
- **安全熔断**：电池不高于 20% 或 macOS 报告严重 thermal pressure 时释放保活。传感器连续读取失败也应释放，而不是继续赌。
- **受限提权**：特权层只接受布尔开/关或两条精确 `pmset` 命令；优先签名 XPC/helper，次选经过 `visudo -cf` 验证的精确 sudoers。禁止开放任意 root 命令。
- **原子状态与恢复**：保存进入前基线、租约持有人和截止时间；写临时文件后原子替换。卸载时先恢复正常休眠，再删除组件。
- **可观察性**：状态命令应报告所有者、剩余时间、电源、电量、温度压力、当前 `SleepDisabled` 和最近一次修复；正常轮询不刷日志。
- **Agent Hook 可选**：用引用计数处理并发任务，最后一个任务释放后才允许休眠；长构建需要显式延长。Hook 不是系统守护的替代品。

## 验收门槛

升级或迁移后至少验证：

1. 启用、禁用和卸载均能恢复正确基线。
2. 电池→插电、插电→电池的检查前状态均正确。
3. 修改一个无关 `pmset` 参数后能按设计恢复或明确报警。
4. 模拟守护退出/租约过期，确认自动恢复正常休眠。
5. 低电量或温度熔断可用模拟输入测试，不通过真实过热测试。
6. 插电和电池的真实合盖测试按用户实际场景分别完成。

任何一项未完成，都只能报告“配置完成”或“部分稳定”，不能报告“彻底解决”。
